Undo the Last Commit (Soft Reset)

This will remove the last commit but keep your files (good if you still want to adjust or recommit something): git reset --soft HEAD~1

If the large file was added 2 commits ago:

git reset --soft HEAD~2

Or, hard reset (discard changes completely — use with caution!) git reset --hard HEAD~1

Remove files from the local and remote repos by force using Git
